Đặc tả tính năng: Kiểm tra nguồn trích dẫn qua MCP & Xem toàn văn tài liệu (Interactive Provenance)

🤖 1. Phía Agent (MCP Protocol)

Hỗ trợ các AI Agent (Cursor, Claude Desktop, Antigravity) chủ động kiểm định trích dẫn và truy cập link trực tiếp.

Tool mới: verify_citation

Cho phép Agent so khớp đoạn trích dẫn (quote) với bản gốc Markdown:

  • Chuẩn hoá khoảng trắng: Chống sai lệch do ngắt dòng (newline) và thụt lề từ LLM.
  • Xác định Section: Tự động bóc tách Heading cha chứa đoạn trích dẫn.
  • SHA-256 Hash: Cung cấp mã hash đảm bảo tính toàn vẹn của file.

Deep Links trong search_knowledge

Kết quả tìm kiếm trả về đồng thời URL Web và giao thức Resource của Agent:

{
  "spec_id": "HR-M05",
  "url": "http://localhost:3000/specs/HR-M05",
  "resource_uri": "spec://HR-M05",
  "snippet": "..."
}

👤 2. Phía Con Người (Human Web UI)

Trải nghiệm xem toàn văn tài liệu trực tiếp trên Web Chat UI không làm gián đoạn luồng trò chuyện.

Right Slide-over Sheet (SpecDrawer)

  • Khi hover vào thẻ Citation Badge -> bấm nút "📖 Xem toàn văn tài liệu".
  • Drawer trượt ra từ cạnh phải với toàn bộ nội dung Markdown (bảng biểu, quy tắc, code block).
  • Hỗ trợ sao chép toàn bộ Markdown và nút mở tab riêng.

Trang Độc Lập: /specs/[id]

Dành cho người dùng hoặc Agent click trực tiếp từ IDE mở ra trình duyệt:

# Kiểm tra xem tài liệu qua URL độc lập
curl -I http://localhost:3001/specs/HR-M05
# HTTP/1.1 200 OK

⚡ 3. Triệt Tiêu Lỗi "Trả Ra Rồi Xoá Mất 2 Lần" (RCA)

Nguyên nhân gốc Cơ chế trước đây Giải pháp triệt để đã áp dụng
Lần 1: Dẫn nhập Tool Model sinh văn bản mào đầu trước khi gọi tool RAG -> frontend nhận event on_tool_start và phát lệnh RESET xoá sạch văn bản. Tối ưu system prompt chỉ thị agent gọi tool ngay lập tức mà không phát biểu dẫn nhập dư thừa.
Lần 2: False-positive Citation Model trích dẫn ID con hợp lệ (UC-PRG-02, TABLE_025) nhưng bị Guardrails phạt nhầm vì không trùng ID cấp cao (HR-M05) -> kích hoạt CORRECTION + RESET. Bổ sung bộ tiền tố _SUB_BLOCK_PREFIXES trong citations.py và kiểm tra đối soát trực tiếp trong nội dung tài liệu đã nạp.
