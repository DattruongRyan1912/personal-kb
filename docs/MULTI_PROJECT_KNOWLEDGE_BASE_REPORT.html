1. Kiến Trúc Phân Vùng Đa Dự Án (Multi-Project Architecture)

Hệ thống phân vùng dữ liệu tri thức theo cấp độ từng dự án độc lập (Partitioned by project_id) xuyên suốt từ tầng lưu trữ vật lý đến tầng UI:

🗄️ Tầng Cơ Sở Dữ Liệu & Vector
• Postgres: Cột project_id text NOT NULL DEFAULT 'Personal-KB' trên bảng chunks và documents kèm index chunks_project_id.
• Zero-downtime Migration: Tích hợp tự động trong ensure_schema() qua lệnh ADD COLUMN IF NOT EXISTS.
• Qdrant: Lưu trường project_id trong payload điểm, lọc chính xác khi truy hồi.
📁 Tầng File System & Ingestion
• Quy ước Nhận diện Kép: Tự động nhận diện dự án từ YAML Frontmatter (project: Demo-Core) HOẶC từ tên thư mục con (knowledge/Demo-Core/*.md).
• Path Traversal Safe: Chuẩn hoá định danh dự án qua regex [^A-Za-z0-9_.-] và hàm safe_create_spec_path().
• Recursive Audit: Sử dụng rglob("*.md") giúp kiểm toán đối soát chính xác 100%, không bị nhận diện nhầm file mồ côi.

2. Đặc Tả Giao Diện Lập Trình (API Endpoints)

Method Endpoint Mô tả & Tham số Dữ liệu trả về
GET /api/v1/data/catalog Liệt kê catalog. Hỗ trợ query ?project=Demo-Core hoặc ?project=ALL. { projects, project_counts, items }
POST /api/v1/data/upload Tải lên spec mới. Nhận file và project_id qua Form-Data. { status, spec_id, project_id, message }
POST /api/v1/data/sandbox/retrieve Kiểm thử truy hồi. Nhận { query, limit, project_id }. { results: [{ spec_ids, project_id, score, ... }] }
POST /api/v1/data/audit Đối soát đĩa với vector DB trên toàn bộ cây thư mục rglob. { total_disk_files, missing_in_db, consistency_percentage }

Mỗi tài liệu trong danh mục hiển thị rõ ràng badge dự án (ví dụ Demo-Core hoặc Personal-KB) với font JetBrains Mono chuẩn Dark Zinc 950.
