3. Tombstone Lifecycle (Triple-Lock)

Đào thải tri thức cũ khi có quyết định thay thế mà không gây mất mát dữ liệu kiểm toán (Audit Trail):

  • • Two-Way Check: Cùng dự án, tài liệu cũ phải đang active
  • • Soft Tombstone: Gắn valid_to = now, superseded_by = new_id
  • • Auto Filter: Qdrant validity_filter tự động ẩn khỏi AI
